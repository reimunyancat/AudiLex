# AudiLex

## 최근 업데이트 (2025-12-21)

### 🏗️ 아키텍처 개편

- **아키텍처 분리**: 시스템을 **Django 백엔드**와 전용 **FastAPI AI 서버**로 분리했습니다.
  - **백엔드**: 데이터 관리, API 요청, 웹소켓 연결을 담당합니다.
  - **AI 서버**: GPU에서 실행되는 무거운 AI 추론(Whisper, LLM)을 위한 전용 노드입니다.

### ✨ 새로운 기능

- **파일 업로드 지원**: 유튜브 링크 외에도 로컬 오디오/비디오 파일을 직접 업로드할 수 있습니다.
- **실시간 업데이트**: 번역 및 발음 작업의 실시간 진행 상황을 보여주기 위해 **웹소켓(WebSockets)**을 구현했습니다.

### 🛠️ 기술적 개선

- **프론트엔드**:
  - **Tailwind CSS v4**로 마이그레이션했습니다.
  - 더 부드러운 사용자 경험을 위해 낙관적 UI 업데이트(Optimistic UI updates)를 추가했습니다.
  - 폴링방식을 웹소켓 이벤트로 대체했습니다.
- **백엔드**:
  - ASGI/웹소켓 지원을 위해 `Django Channels`와 `Daphne`를 통합했습니다.
  - AI 서버와 통신하도록 API 뷰를 리팩토링했습니다.
